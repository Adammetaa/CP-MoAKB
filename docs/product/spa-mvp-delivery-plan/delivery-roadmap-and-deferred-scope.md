# Delivery Roadmap and Deferred Scope

Status: Active

Version: 1.0

## Shortest Safe Roadmap

1. approve this Delivery and Validation Plan;
2. govern the Rice Knowledge Vertical Slice and Human Review Operating Model;
3. define, implement under future authority, and validate Increment A in Round 1;
4. define, implement under future authority, and validate Increment B in Round 2;
5. define, implement under future authority, and validate Increment C in Round 3;
6. run Round 4 integrated validation and seek SPA MVP Pilot Completion approval.

Round 0 precedes field use. Dependency-safe streams in the readiness map may run
in parallel, but no handoff is assumed complete before review.

## Owner Approval Points

The Owner explicitly approves increment scope, pilot crop/family, participants,
reviewer assignment, sensitive-data handling, Case sample, validation start,
stop resolution, increment acceptance, expansion, and production eligibility.
Owner approval cannot waive missing scientific, privacy, regulatory, or governance authority.

## Deferred Scope and Authorization Prerequisites

| Deferred item | Prerequisite for future authorization |
|---|---|
| software implementation | approved increment Product Definition, architecture, acceptance, and implementation sprint |
| UI design | validated field/user needs and approved interaction-design scope |
| technical permissions | approved role/authority model, privacy threat review, and identity architecture |
| API, schema, database, identifiers | approved implementation architecture and protected-contract review |
| synchronization design | offline conflict, provenance, privacy, and safety requirements plus technical authority |
| production dataset or Knowledge Package authoring | governed sources, licensing, qualified reviews, package lifecycle, and publication decision |
| automatic question selection | validated advisory applicability research, neutrality, explanation, and human confirmation |
| Image Intelligence | governed corpus, consent, evaluation, uncertainty, provenance, and reviewer control |
| automatic hypothesis ranking | separately approved advisory research with no hidden score or winner |
| automatic Diagnosis | diagnostic authority, scientific validation, safety, liability, and Human Review governance |
| Management Option generation | reviewed investigation, product/regulatory/safety knowledge, eligibility, and option governance |
| product recommendation | Recommendation authority, label/regulatory review, neutrality, and human decision boundary |
| self-learning | Learning Candidate and Approved Knowledge Package governance with no raw-case promotion |
| enterprise analytics | multi-case privacy, aggregation, metric, authority, and oversight design |
| multi-crop rollout | independently governed crop packages, localization, qualified review, and pilot evidence |

## Strategic Alignment

Increments establish the traceable manual foundation for future Explainable AI
without depending on it. The pilot is not a chatbot trial: it validates structured
case continuity, governed knowledge, Human Review, field practicality, and honest
unresolved outcomes. Field learning enters only through Learning Candidate and
Knowledge Review governance.

## Production Boundary

Pilot completion does not create production eligibility. Production requires a
separate Owner decision and all applicable operational, scientific, privacy,
security, regulatory, governance, release, and publication readiness.
