# Explainability Presentation Model

Status: Active

Version: 1.0

## Explainability Questions

For each eligible representation, the Website should help a user understand:

- why the canonical object exists and which purpose it serves;
- where it originated and which exact sources or predecessor versions apply;
- how it relates to other knowledge through asserted relationships;
- who authored, owns, and reviewed it under which authority;
- its Review State, publication state, version, and lifecycle;
- which transformations, translations, or summaries produced the representation;
- known omissions, limitations, conflicts, and unresolved issues; and
- what the representation must not be interpreted to mean.

## Explanation Chain

An explanation links the Website Representation to the exact canonical version,
provenance, Source, Authority, Review, relevant Relationships, Package context,
lifecycle events, and Publication Record where eligible. Each link is explicit;
the chain does not infer scientific conclusions.

## Layer-aware Explanation

Observation, Evidence, Knowledge, Hypothesis, Diagnosis, Recommendation,
Decision, Action, and Outcome remain visibly distinct. Investigation examples
must distinguish gaps from negative Observations, needs from Evidence Objects,
candidates from Diagnosis, and Findings from Claims or Recommendations.

## Limitations First

Limitations needed to interpret a representation appear with the substantive
meaning, not only in a remote disclaimer. Summaries disclose material omissions
and provide a path to fuller eligible context.

## Human Review Boundary

Review status names exact scope and authority. “Reviewed” does not mean true for
all purposes, published, recommended, or applicable to a user’s case. Reviewer
disagreement and unresolved status remain visible where eligible.

## Auditability

Explanation fidelity is reviewable against the canonical version and preserved
across navigation, discovery, localization, and view composition. Website
analytics or user behavior cannot silently change the explanation.
