# Provenance and Version Model

Status: Active

Version: 1.0

## Purpose

Website presentation must never hide scientific or governance status. Users
must be able to distinguish where content came from, which version is shown, who
holds authority, what review occurred, and whether later lifecycle events apply.

## Presentation Responsibilities

| Responsibility | Required meaning |
|---|---|
| provenance | origin, authorship, custody, transformations, derivation, language work, and relevant history |
| authority | exact authority role and scope, not merely organization or reputation |
| Review State | status, purpose, reviewer, date, rationale/conditions, conflicts, and limitations where eligible |
| publication state | not published, candidate, eligible, published, withdrawn, or other governed state without inference from reachability |
| canonical version | exact Knowledge Asset or object version represented and its compatibility context |
| Representation Version | exact Website expression version, purpose, audience, language, omissions, and fidelity review |
| supersession | explicit predecessor/replacement relationship, effective context, reason, and preserved history |
| deprecation | discouraged-use status, rationale, limitations, and replacement where one exists |

## Version Separation

Canonical Knowledge Version, Representation Version, Knowledge Package Version,
governance-document version, Product version, Runtime version, and Publication
identity remain independent. Coordinated presentation records compatible exact
versions rather than assigning a shared version.

## Current and Historical Views

“Current” means current under a declared canonical lifecycle decision for a
purpose; it does not erase history. Historical eligible representations display
their past status and replacement context and must not appear current through navigation.

## Corrections

A canonical scientific correction follows owning governance and may require a
new Knowledge Version, withdrawal, supersession, and notification. A Website
fidelity correction may create a new Representation Version without changing
canonical meaning. The Website never silently edits history.

## Unavailable Provenance

Missing or unresolved provenance is shown as a limitation or blocks the claimed
presentation purpose. It is never filled by inference or hidden to improve readability.
