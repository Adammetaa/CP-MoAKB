# Relationship Presentation Model

Status: Active

Version: 1.0

## Principle

The Website presents only governed canonical relationships or explicit
presentation cross-references whose non-canonical status is clear. It never
infers, predicts, composes, ranks, or silently creates relationships.

## Required Relationship Context

An asserted relationship presentation identifies:

- exact source and target canonical versions;
- governed relationship type and direction;
- definition and scope of that relationship;
- authoring or assertion basis;
- authority, review, and lifecycle status;
- applicable language or terminology context;
- known limitations, conflicts, and unresolved issues; and
- representation version and omissions.

## Presentation Forms

Text links, lists, tables, diagrams, and graph-like views are interchangeable
presentation abstractions only when they preserve the same asserted meaning.
Visual proximity, line direction, color, size, order, grouping, or animation
must not introduce importance, causality, equivalence, or recommendation.

## Canonical Versus Editorial Links

A canonical relationship carries exact governed semantics. An editorial
cross-reference merely helps navigation and must be labeled as such with its
purpose. Editorial links cannot be exported, counted, or displayed as canonical relationships.

## Non-composition

If A relates to B and B relates to C, the Website does not assert that A relates
to C. Shared Source, Package, label, reviewer, Topic, or navigation path creates
no equivalence, support, challenge, or causal relationship.

## Conflicts and Lifecycle

Conflicting, deprecated, superseded, withdrawn, or unresolved relationships are
presented only when eligible, with status and replacement context. The Website
does not choose among conflicts; it shows the governed disposition and limits.
