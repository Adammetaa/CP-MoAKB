# Website Knowledge Model

Status: Active

Version: 1.0

## Definition

The Website Knowledge Model defines how canonical knowledge is organized,
navigated, discovered, related, filtered, explained, and presented through the
Website Alpha experience. It is a presentation, integration, and navigation model.

It defines how knowledge appears, not what knowledge is.

## Permanent Boundary

The model is not the source of truth, a new Knowledge Object Model, Ontology,
Vocabulary, Website-specific knowledge database, or replacement for Canonical
Knowledge Architecture. The Canonical Knowledge Model remains the permanent
single source of truth.

Website representations consume governed canonical knowledge without altering
scientific meaning, authority, traceability, provenance, Review State,
publication state, or version identity.

## Authority

The [Website Alpha Architecture](../website-alpha/README.md),
[Knowledge Object Model](../../knowledge/object-model/README.md), and canonical
[Representation Object](../../knowledge/object-model/object-classes/representation-object.md)
retain authority. This model does not modify them.

## Out of Scope

No Runtime, API, schema, database, Website implementation, page, component,
search engine, index, canonical knowledge, dataset, inference, AI, Diagnosis,
Recommendation, product selection, review workspace, analytics, deployment,
release, or publication artifact is created.
