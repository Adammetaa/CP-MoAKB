# Localization Presentation Model

Status: Active

Version: 1.0

## Thai-first Principle

Website knowledge presentation supports Thai as a preferred audience language
while preserving explicit English technical alignment, canonical identity,
source expression, translation provenance, Review State, and uncertainty.
Thai-first does not mean Thai-only or translation-first canonical authoring.

## Label Responsibilities

- **Preferred label:** the governed preferred expression for a declared language,
  locale, audience, and purpose.
- **Alternative label:** a governed synonym, variant, local expression, or
  search aid with relationship and status disclosed.
- **English alignment:** the reviewed relationship to an English technical
  expression; it is not automatically exact equivalence or canonical priority.
- **Terminology note:** eligible guidance on ambiguity, scope, usage, register,
  transliteration, uncertainty, and prohibited interpretation.

## Canonical Meaning

Localization never creates a new Concept, merges Concepts, confirms scientific
identity from a local name, upgrades a label’s status, changes relationship
semantics, or hides a canonical limitation. New meaning requires canonical
Knowledge and terminology governance.

## Representation Requirements

A localized representation identifies exact canonical version, Representation
Version, language/locale, translator or transformation responsibility, source
language, terminology basis, review, omissions, known ambiguity, and fidelity statement.

## Navigation and Discovery

Users may discover an eligible canonical object through preferred or alternative
labels, but the result explains which label matched and shows the stable
canonical reference. Language match does not increase scientific relevance or rank.

## Missing Translation

Unavailable or pending translation remains explicit. The Website may show an
eligible fallback only with language clearly marked; it must not invent a label,
silently machine-translate, or conceal missing review.
