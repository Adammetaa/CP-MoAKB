# Website Knowledge Composition Model

Status: Active

Version: 1.0

## Definition

The Website Knowledge Composition Model defines how approved Knowledge Views are
assembled into Website pages, sections, presentation components, and navigational
structures. Composition preserves semantic integrity, canonical identity,
provenance, authority, Review State, publication state, version identity, and
traceability.

It defines composition only. It does not define, redefine, or authorize knowledge.

## Permanent Boundary

This model is not the Canonical Knowledge Model, a new Knowledge Object Model, a
Website-specific knowledge database, a content-authoring model, an AI-generated
knowledge layer, a Runtime UI framework, a page-rendering engine, a CMS content
model, or a navigation-execution model.

Canonical Knowledge remains authoritative. A composed page presents governed
Knowledge Views and never becomes Knowledge or a Knowledge Object.

## Authority

The [Website Knowledge Model](../website-knowledge-model/README.md),
[Website Alpha Architecture](../website-alpha/README.md), canonical Knowledge
Architecture, and Program Governance retain authority. This model only composes
approved representations supplied under those authorities.

## Out of Scope

No software, Runtime code, API, database schema, UI implementation, React
component, renderer, route, CMS, canonical knowledge, release, deployment, or
publication artifact is created.
