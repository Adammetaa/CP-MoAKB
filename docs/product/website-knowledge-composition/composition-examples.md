# Composition Examples

Status: Active

Version: 1.0

## Interpretation

These are architecture illustrations only. Arrows mean conceptual inclusion,
not data flow, Runtime execution, inference, promotion, or canonical derivation.

## Knowledge Detail Illustration

> Concept View + Source View + Relationship View + Explainability View
> -> identity, meaning, sources, related knowledge, and limitations Sections
> -> Knowledge Detail Page

Each View retains its exact identity and version. The related-knowledge Section
distinguishes asserted Relationships from editorial navigation.

## Investigation Illustration

> Investigation View + Observation View + Evidence View + Review View
> -> investigation context, observations, evidence, and review Sections
> -> Investigation Page

Composition does not promote an Observation to Evidence, choose a candidate,
perform Diagnosis, or turn Review into publication.

## Observation Illustration

> Observation View + Source View + Provenance View + Limitation View
> -> bounded record, origin, context, and limitations Sections
> -> Observation Page

Adjacency to a Source or Concept does not assert causality or applicability.

## Package Illustration

> eligible member Knowledge Views + Package View + Version View
> -> scope, membership, compatibility, review, and limitations Sections
> -> Knowledge Package Page

The Page presents exact eligible membership; it is not itself a canonical
Knowledge Package and does not imply that every referenced item is public.

## Reuse Illustration

One approved Source View may appear in several Pages. Each placement records its
Section purpose while retaining identical canonical reference, Representation
Version, provenance, authority, Review State, and publication condition.
