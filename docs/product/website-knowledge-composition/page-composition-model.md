# Page Composition Model

Status: Active

Version: 1.0

## Definition

A Website Page is a conceptual presentation assembly of eligible Knowledge Views
organized into purpose-bounded Sections. A Page is composed from Knowledge Views,
not directly from Canonical Objects.

## Page Contract

Each conceptual Page declares:

- presentation purpose and intended audience;
- page pattern and section sequence;
- included Knowledge Views and exact representation versions;
- inclusion and exclusion rationale;
- traceability and explainability expectations;
- visibility and publication eligibility; and
- limitations, unresolved conflicts, supersession, and deprecation context.

## Separation from Knowledge

A Page is not Knowledge, a Knowledge Object, a canonical package, or publication
authority. Its title, order, prominence, adjacency, summary, or navigational
placement cannot create a canonical Relationship, ranking, Claim, Finding,
Diagnosis, Recommendation, or Decision.

## Composition Behavior

Pages may reuse eligible Views, group them into Sections, and provide orientation
that accurately describes their asserted relationships. They must expose the
identity and status needed to trace material statements through the View to
Canonical Knowledge.

## Implementation Neutrality

This model defines no page route, renderer, template language, component tree,
query, API response, cache, responsive layout, interaction, or Runtime behavior.
