# Website Alpha Architecture

Status: Active

Version: 1.0

## Purpose

Website Alpha is the first public-facing product architecture built on the
governed Knowledge Foundation. It exposes governed knowledge, structured
investigation, evidence relationships, Human Review boundaries, and explainable
reasoning without implementing AI automation.

## Product Evolution

> Website Alpha -> SPA Alpha -> Field Pilot -> Production -> Enterprise Platform

Each step requires separate Product, Architecture, Knowledge, Validation,
Release, and Publication governance. Website Alpha does not authorize later stages.

## Knowledge-first Flow

> Knowledge -> Observation -> Investigation -> Evidence -> Human Review -> Explainability

The flow is navigational and explanatory. It does not create inference,
Diagnosis, Recommendation, ranking, workflow automation, or promotion between layers.

## Out of Scope

This family creates no Website implementation, page, component, React code,
Runtime behavior, API, database, schema, UI design, dataset, analytics,
automation, AI, image classification, Diagnosis, pesticide Recommendation,
