# Website Roadmap

Status: Active

Version: 1.0

## Evolution Stages

| Stage | Product value | Required foundations | Boundary |
|---|---|---|---|
| Website Alpha | public-oriented governed browsing and explanation | approved architecture, eligible Knowledge representations, content/navigation definition, publication decisions | no case work, AI, Diagnosis, Recommendation, or production claim |
| SPA Alpha | role-bounded manual investigation capability | SPA MVP increments, Human Review operation, crop Vertical Slice, privacy/authority, implementation and validation | manual-first; no autonomous inference |
| Field Pilot | validate real remote/field continuity and review | approved sample, participants, evidence package, stop/rollback plan, offline expectations | validation is not scientific diagnostic proof |
| Production | authorized reliable operation for approved scope | all Program gates/DoDs, security/privacy/regulatory/support/rollback, Owner and Office concurrence | Production Release is not Publication or Enterprise scope |
| Enterprise Platform | multi-role/multi-crop oversight and governed scaling | validated production, package governance, organization/privacy model, analytics governance, capacity and risk evidence | no automatic authority consolidation or autonomous advice |

## Alpha Critical Path

> Website Alpha Architecture -> publication-eligible content inventory -> Website
> content and interaction definition -> implementation architecture -> authorized
> implementation -> documentation/accessibility/security validation -> Alpha
> Release Candidate -> separate Release and Publication decisions

This sprint completes only the first step.

## Parallel Preparation

Knowledge eligibility review, Thai-first terminology alignment, documentation
cross-reference review, source/provenance representation requirements,
accessibility research, and future SPA handoff analysis may proceed in parallel.
None may assume a page design, API, implementation, Release, or Publication.

## Roadmap Governance

Program Management coordinates dependencies, but Product, Architecture,
Knowledge, Scientific, Release, and Publication authorities decide their own
readiness. The roadmap returns or pauses on boundary collapse, unavailable
eligible content, unclear audience, hidden ranking, publication uncertainty, or
scope expansion into deferred capabilities.
