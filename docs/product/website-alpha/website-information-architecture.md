# Website Information Architecture

Status: Active

Version: 1.0

## Top-level Structure

| Area | Purpose | Included meaning | Excluded meaning |
|---|---|---|---|
| Home | orient visitors to mission, boundaries, and available Alpha paths | product identity, knowledge-first promise, current status, clear next destinations | chatbot input, diagnosis prompt, personalized advice |
| Knowledge | browse governed knowledge families and packages | concepts, claims, terms, sources, evidence/review/publication context where eligible | duplicate knowledge records, inferred conclusions, product promotion |
| Investigation | explain the human-governed investigation flow | Observation, states, gaps, questions, evidence needs, candidates, differential, review, findings | active case workflow, automatic question selection, Diagnosis |
| Knowledge Explorer | traverse eligible objects, relationships, provenance, versions, and limitations | neutral filters, exact references, object views, relationship explanation | hidden rank, similarity Diagnosis, ungoverned graph inference |
| Learning | explain governed feedback from field outcomes to Learning Candidates and review | nomination categories, no-promotion rule, lifecycle and governance | raw-case self-learning or automatic Knowledge updates |
| About | explain Program identity, governance, scope, status, and authorities | vision, principles, offices, release/publication boundary, limitations | marketing claims beyond evidence or production-readiness implication |
| Future SPA Workspace | make the evolution path visible without pretending it exists | conceptual SPA case journey, manual-first boundaries, future prerequisites | functional workspace, form, account actions, field data collection |

## Structural Principles

The primary structure follows user meaning, not repository folders or object
storage. Knowledge and Investigation remain distinct but cross-reference through
explicit governed relationships. Explorer is a presentation mode over eligible
knowledge, not another source of truth. Learning is governance education, not a data feed.

## Content Classes

The Website may present eligible Program explanations, knowledge-package
summaries, object representations, source/provenance accounts, investigation
architecture, glossaries, limitations, review/publication status, and documentation.
Each class has an owning authority and exact source reference.

## Scalability

The structure can later add role-specific workspaces, crop packages, Human
Review, field pilots, and enterprise oversight without relocating or redefining
the public Knowledge Foundation. New areas require separate Product and
Publication decisions.
