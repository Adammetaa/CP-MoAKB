# Rice Website Golden Vertical Slice

Status: Active

Version: 1.0

## Definition

The Rice Website Golden Vertical Slice is a documentation-only specification of
the smallest architecture-complete Website knowledge journey. It demonstrates:

> Approved Canonical Knowledge -> Knowledge Views -> Website Composition ->
> conceptual Website Pages

The slice covers a Rice Overview, Rice Growth Stage, one governed Disease, one
governed Insect, one governed Weed, Observation, Evidence, Source, Related
Knowledge, Management Knowledge reference, and Mode of Action reference.

## Boundary

The slice validates architecture, not biological completeness. It is not a rice
dataset, Knowledge-authoring sprint, Runtime implementation, Diagnosis or
Recommendation workflow, product catalogue, CMS, AI workflow, Image Intelligence,
or Active Investigation.

No example in this family asserts crop facts or selects a biological entity.
Named slice roles are filled only by separately governed, eligible canonical content.

## Authority

The [Website Knowledge Model](../website-knowledge-model/README.md),
[Website Knowledge Composition Model](../website-knowledge-composition/README.md),
Website Alpha, Canonical Knowledge Architecture, and Program Governance retain
authority. This specification consumes approved Views without modifying them.

## Out of Scope

No software, Runtime, UI, React component, API, schema, database, route,
agricultural content, canonical object, release, deployment, or publication
artifact is created.
