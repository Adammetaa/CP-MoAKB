# Rice Growth Stage Page Specification

Status: Active

Version: 1.0

## Purpose

Specify how one separately selected, governed Rice Growth Stage representation
can be presented and connected to the Golden Slice without authoring crop content.

## Required Composition

| Section responsibility | Required Views and controls |
|---|---|
| identity and terminology | eligible Concept/Identity and Terminology Views with exact canonical and representation versions |
| stage context | approved Growth Stage Knowledge View with scope, authority, provenance, review, and limitations |
| asserted relationships | Relationship Views showing type, direction, basis, source, target, version, and Review State |
| sources and explanation | Source, Provenance, Review, Version, Limitation, and Explainability Views |
| slice navigation | identified canonical Relationship or explicitly editorial navigation to eligible detail Pages |

## Governance

The selected stage requires canonical readiness, compatible Views, review
readiness, rights clearance, and publication eligibility for the intended
audience. Composition cannot create or adjust stage definitions, boundaries,
sequence, applicability, or Relationships.

## Traceability

Every Section preserves: Section -> Knowledge View -> Canonical Object ->
Canonical Knowledge. Summaries retain references to all supporting Views.

## Exclusions

No growth-stage facts, calendars, thresholds, agronomic interpretation, pest
association, Diagnosis, Management action, Recommendation, or Runtime behavior
is defined by this specification.
