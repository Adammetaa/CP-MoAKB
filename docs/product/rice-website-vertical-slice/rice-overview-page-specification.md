# Rice Overview Page Specification

Status: Active

Version: 1.0

## Conceptual Page Contract

| Concern | Specification |
|---|---|
| purpose | orient users to the governed Rice knowledge scope and available slice destinations |
| audience | public knowledge explorer, educator, reviewer, and product architect within their visibility rights |
| required Knowledge Views | eligible Identity/Concept, Terminology, Source, Review, Provenance, Version, Limitation, and Explainability Views |
| optional Knowledge Views | eligible Growth Stage, Relationship, Package, and Related Knowledge Views |
| required relationships | only exact canonical links supporting included Growth Stage and selected detail destinations |
| required provenance | exact canonical identities/versions, View versions, sources, authority, transformations, and language provenance |
| required review visibility | Review State, scope, authority, date, conditions, dissent, and unresolved limitations where eligible |
| required publication visibility | publication state and audience eligibility; Website reachability is not publication |
| required traceability | every Section traces through its Knowledge View to exact Canonical Objects and provenance |
| explicit exclusions | crop facts authored here, comprehensive coverage, ranking, Diagnosis, Recommendation, product choice, inferred links, Runtime behavior |

## Conceptual Sections

The Page may compose identity and scope, terminology, Growth Stage navigation,
selected slice destinations, sources and governance, and limitations Sections.
Each Section declares its purpose and identifies editorial navigation separately
from canonically asserted Relationships.

## Meaning Boundary

The Page is not a canonical Rice object or dataset. Ordering and prominence do
not establish scientific importance, sequence, authority, or completeness.
