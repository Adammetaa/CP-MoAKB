# Disease Detail Page Specification

Status: Active

Version: 1.0

## Purpose

Specify the conceptual composition for exactly one separately governed and
eligible Disease role in the Golden Slice. This document does not select, name,
describe, or author a disease.

## Eligible View Responsibilities

| View | Page responsibility |
|---|---|
| Identity View | exact canonical identity, type, scope, and version |
| Terminology View | governed preferred/alternative labels, language, and status |
| Observation View | neutral bounded observations with context, uncertainty, and provenance |
| Relationship View | only exact asserted links with type, direction, basis, and review |
| Evidence View | scoped Evidence role, Source, authority, review, and limitations |
| Source View | source identity, version, publication, authority context, and provenance |
| Review View | purpose, scope, authority, status, rationale, conditions, and dissent |
| Related Knowledge View | asserted Relationships or clearly marked editorial navigation |
| Limitation View | uncertainty, omissions, restrictions, and non-implications |

## Required Sections

Identity and scope, observations, evidence and sources, asserted relationships,
review and provenance, Related Knowledge, Management reference where eligible,
and limitations may be composed as distinct traceable Sections.

## Diagnosis Boundary

The Page must not imply Diagnosis. Observation similarity, adjacency, frequency,
Evidence, page order, or user navigation cannot identify a cause, select an
explanation, establish applicability, or create a case conclusion.

## Implementation Boundary

No symptom checker, input, scoring, ranking, workflow, UI, route, or Runtime
behavior is specified.
