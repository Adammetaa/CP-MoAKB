# Mode of Action Reference Page Specification

Status: Active

Version: 1.0

## Purpose

Define a conceptual reference Page for one separately governed, eligible Mode of
Action representation needed to validate traceability and cross-domain reference
boundaries. This document defines no Mode of Action knowledge.

## Required Views

The Page requires eligible Identity/Concept, Terminology, Source, Relationship,
Review, Provenance, Version, Limitation, and Explainability Views. Each View
retains exact canonical identity, authority, publication state, review scope,
version, provenance, and limitations.

## Reference-only Rule

Mode of Action is Reference only. It is never:

- a Treatment Recommendation;
- a Product Recommendation;
- a Resistance Decision;
- evidence that an action is suitable, authorized, registered, safe, or effective;
- a substitute for label, regulatory, scientific, or Human Review authority; or
- a ranking, selection, prioritization, or case-specific conclusion.

## Relationships

Only canonically asserted Relationships may be presented. A link from a Disease,
Insect, Weed, Management, or other Page does not create applicability or advice.
Editorial navigation remains labeled as navigation.

## Traceability and Governance

Every Section traces through the exact Knowledge View and Canonical Object to
Canonical Knowledge and Source provenance. Unknown eligibility, version,
authority, review, or publication state blocks the claimed public purpose.

## Implementation Boundary

No product lookup, filter, resistance calculator, decision support, active case,
UI, API, data model, or Runtime behavior is specified.
