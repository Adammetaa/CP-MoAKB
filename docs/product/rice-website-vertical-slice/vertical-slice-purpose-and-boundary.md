# Vertical Slice Purpose and Boundary

Status: Active

Version: 1.0

## Purpose

The Golden Slice tests whether the Website Knowledge Architecture can specify an
end-to-end, explainable, traceable presentation journey without creating another
Knowledge Base. It is intentionally narrow but exercises all material boundaries.

## Slice Chain

> Rice Overview -> Rice Growth Stage -> one Disease -> one Insect -> one Weed ->
> Observation View -> Evidence View -> Source View -> Related Knowledge ->
> Management Knowledge Reference -> Mode of Action Reference

The arrows describe architecture coverage and possible governed navigation, not
canonical relationships, biological sequence, causality, ranking, or Runtime flow.

## Permanent Separations

| Slice responsibility | Must remain separate from |
|---|---|
| page specification | page implementation, route, renderer, or CMS record |
| selected role | authored rice knowledge or new canonical identity |
| Observation presentation | Diagnosis, Evidence promotion, or causal interpretation |
| Evidence presentation | Claim creation or universal proof |
| Management reference | recommendation, selection, prioritization, or Decision |
| Mode of Action reference | treatment, product, or resistance Decision |
| Related Knowledge | inferred or generated Relationship |

## Integrity Requirements

Every Page and Section consumes eligible Knowledge Views, preserves exact
canonical and representation identity, provenance, authority, Review State,
publication state, versions, limitations, and traceability, and declares what it
does not imply.

## Content Boundary

This family defines required types and governance conditions only. It neither
names nor describes the crop, growth stage, disease, insect, weed, management
knowledge, Mode of Action, Observation, Evidence, or Source chosen for validation.
