# SPA MVP Definition

Status: Active

Version: 1.0

## Product Definition

The SPA MVP is the smallest safe and useful product slice that enables a
Service Provider Advisor (SPA) to receive, structure, investigate, review,
explain, and follow up an incomplete crop-protection case. It is an Explainable
Crop Investigation Platform, not a classifier, pesticide recommendation engine,
agricultural chatbot, automatic diagnosis system, or autonomous advisor.

The SPA is the primary user. Agronomist, Scientific, Knowledge, and Governance
reviewers are secondary participants. Service Providers, Dealer Advisors, Crop
Advisors, enterprise users, and farmers are future or non-primary users.

## Authority

The [Investigation Blueprint](../investigation-blueprint/README.md) controls the
product journey. The [Investigation Ontology](../../knowledge/investigation/README.md)
and [Question Bank Architecture](../../knowledge/investigation-question-bank/README.md)
control investigation and question boundaries. Existing knowledge, evidence,
review, Design Freeze, and Publication Boundary authorities remain unchanged.

## Permanent Separation

Reported Information is not Direct Observation. Observation is not Evidence.
Evidence Need is not Evidence Object. Knowledge Reference is not Case Evidence.
Information Gap is not Negative Observation. Question Pattern is not Question
Instance. Hypothesis Candidate is not Diagnosis. Differential Comparison is not
automatic ranking. Investigation Finding is not Claim. Management Option is not
Recommendation or Decision. Decision, Action, and Outcome remain distinct.
Outcome does not rewrite prior records.

No layer automatically creates, promotes, converts, or rewrites another layer.

## MVP Value Before Image Intelligence

The MVP creates value through disciplined case structure, visible uncertainty,
manual question selection, evidence provenance, governed knowledge consultation,
explicit competing hypotheses, Agronomist review, explanation chains, follow-up,
and outcome capture. Images are contextual material for human review, not
machine-generated diagnosis.

## Out of Scope

This definition creates no software, Runtime behavior, schema, API, database,
identifier, UI, wireframe, visual design, dataset, production record, diagnosis,
pesticide program, product recommendation, scoring, ranking, AI, automatic
workflow, or release artifact.
