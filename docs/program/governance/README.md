# CP-MoAKB Program Governance Architecture

Status: Active

Version: 1.0

## Program Identity

CP-MoAKB is a governed scientific knowledge and investigation program supporting
an Explainable Crop Investigation Platform. It is not merely software, AI,
documentation, a crop-diagnosis tool, pesticide recommendation system, or
agricultural chatbot.

## Program Direction

> Knowledge -> Investigation -> Human Review -> Product -> Implementation ->
> Validation -> Release -> Operation -> Learning -> Governed Program Evolution

No phase silently replaces or bypasses another. Program Governance coordinates
independent authorities; it does not absorb their decisions.

## Permanent Principles

Knowledge First, Evidence First, Investigation First, explainability,
deterministic traceability, Human-in-the-loop, Product before Implementation,
scientific integrity, reviewability, crop independence, Thai-first compatibility,
implementation neutrality, Design Freeze, Publication Boundary, and no automatic
promotion, Diagnosis, Recommendation, or self-learning from unreviewed cases are permanent.

Observation, Evidence, Knowledge, Hypothesis, Diagnosis, Recommendation,
Decision, Action, and Outcome remain separate.

## Authority Boundary

Existing ADR, RAS, Knowledge Constitution, KAS, KGS, Design Freeze, Publication
Boundary, scientific, privacy, regulatory, and release authorities remain
controlling in their scopes. This family creates coordination, evidence, and
escalation semantics only; it does not reassign existing authority.

## Out of Scope

No Runtime, schema, API, database, identifier, UI, project-management tool,
Jira workflow, board, actual backlog/register, template, estimate, deployment,
automation, dataset, scoring model, AI, release, or publication artifact is created.
