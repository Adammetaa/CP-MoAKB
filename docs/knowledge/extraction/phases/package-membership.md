# Package Membership Proposal

Only approved exact Knowledge Asset/Object versions may enter a Package
Membership Proposal. The proposal records exact Package/member versions, purpose,
role, inclusion authority, dependency/compatibility, rights, review, publication
role, limitations, exclusions, and replacement history.

Membership proposal must never imply acceptance, ownership transfer, Evidence
sufficiency, publication, applicability, or consumer eligibility. Package layout
does not create Knowledge or Relationships.

The proposal enters the Review Queue for separate Package Composition Review.
Acceptance and later Publication Authorization remain independent decisions.
