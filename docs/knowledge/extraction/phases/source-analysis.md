# Source Analysis

Before extraction, the Author and competent reviewers identify exact Source
identity/version, document scope, publisher, authority scope, rights, publication
and retrieval dates, jurisdiction, methods, scientific limitations, corrections,
unsupported areas, availability, and intended extraction purpose.

Unknown identity, version, rights, authority, access, or material context blocks
the dependent extraction. Source authority is scoped and never establishes truth.
The analysis records relevant Sections without treating headings as scientific meaning.

Output is a reviewed analysis and extraction boundary, not Evidence or Knowledge.
