# Relationship Authoring

A Relationship Candidate is created only when reviewed Evidence supports an
explicit source Concept, governed predicate, target Concept, direction, scope,
context, qualifiers, assertion status, limitations, and exact versions.

Navigation, adjacency, same page, same Package, shared Source, co-occurrence,
string match, hierarchy, or graph path must never imply a Relationship. Inverse,
transitive, causal, diagnostic, regulatory, safety, and recommendation meanings
require their own explicit Evidence and competent review.

Relationships are never hallucinated or inferred to complete a graph. A missing
edge remains absent or an Unresolved Issue.
