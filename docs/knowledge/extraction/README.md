# Knowledge Extraction Specification

Status: Active

Version: 1.0

## Purpose

KES is the only approved human authoring pathway for transforming an intake-
reviewed Source into candidates for existing governed Knowledge Objects. It
standardizes sequence, traceability, review handoffs, quality controls, and audit.

KES does not redesign or instantiate Source, Evidence, Claim, Concept,
Terminology, Relationship, Package Membership, Review, or Publication models.
It creates no agricultural Knowledge, Runtime behavior, schema, or automation.
