# Prohibited Extraction Shortcuts

The following are explicitly prohibited:

- ChatGPT memory or chat transcript as Evidence;
- copying conclusions without bounded passage context and review;
- automatic summarization as accepted Evidence or Claim;
- automatic ontology generation;
- automatic Diagnosis or Recommendation;
- hallucinated Relationships, Concepts, or Terminology;
- Source-to-Claim, Evidence-to-Concept, or Concept-to-Package skipping;
- treating validation, review, membership, repository presence, or Website display as Publication;
- hiding uncertainty, adverse Evidence, rights limits, or missing Citations; and
- using model confidence, popularity, adjacency, or UI copy as authority.

Automation may assist clerical presentation only under separately approved scope;
it cannot make semantic or governance decisions.
