# Extraction Authoring Boundaries

KES coordinates existing responsibilities only. Source analysis does not accept
Evidence; Evidence extraction does not author Claims; Claim review does not mint
Concepts; terminology does not create identity; Relationship authoring does not
infer edges; Membership proposal does not accept or publish a Package.

Authors, Evidence Reviewers, Scientific Reviewers, Terminology Reviewers,
Ontology Reviewers, Package Reviewers, and Publication Authority act only within
their existing competence and authority. No role silently performs another stage.

No real agricultural Knowledge, active Case, Diagnosis, Recommendation, consumer
content, production data, or implementation artifact is authorized here.
