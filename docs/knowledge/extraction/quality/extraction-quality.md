# Extraction Quality Controls

Every extraction verifies exact Source/version, complete Citation and locator,
passage fidelity, context, scope, rights, authority fit, jurisdiction/time,
methods, limitations, conflicts, translation, candidate/object separation,
review competence, and bidirectional traceability.

Mandatory failure controls cover missing Evidence, ambiguous wording,
unsupported certainty, conflicting Source material, multiple interpretations,
rights limitation, incomplete Citation, context stripping, invented precision,
hidden adverse material, and floating versions.

Failures block or return the affected stage. They are never repaired by guessing,
confidence scoring, stronger wording, omitted qualifiers, or silent harmonization.
