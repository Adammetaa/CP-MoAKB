# Source Catalog and Minimum Inventory

## Catalog Responsibility

The catalog records only governed identity, authority scope, coverage, status,
rights, and Package suitability. A catalog entry is not Evidence, Knowledge,
authoring readiness, acquisition, integration, or publication.

## IRAC Trace

IRAC identity is governed by `data/official/IRAC/source_manifest.yaml`, with
retrieval controls in `references/IRAC/retrieval.md`. The copyrighted PDF is not
distributed. Availability means the governed identity and controlled retrieval
path exist; it does not mean scientific Claims have been extracted.
