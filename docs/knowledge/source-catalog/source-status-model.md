# Source Status Model

Status: Active

Version: 1.0

| Status | Meaning |
|---|---|
| Available | exact governed identity and approved access path exist for stated use |
| Partially Available | some governance or representation exists, but required material or metadata is incomplete |
| Unavailable | required Source material is not accessible as a governed artifact |
| Pending Acquisition | candidate is identified but has not been governedly obtained |
| Pending Rights | intended use is blocked until rights are decided |
| Pending Review | fixed Source registration awaits competent review |
| Retired | Source is no longer eligible for new use; history remains |
| Superseded | an explicit newer Source version replaces it for declared purposes |

Status describes Source readiness only. It does not establish Evidence quality,
Claim acceptance, authoring readiness, truth, publication, or Package suitability.
Transitions require explicit custody, rationale, review, and audit; none is automatic.
