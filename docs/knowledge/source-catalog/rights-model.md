# Source Rights Model

Status: Active

Version: 1.0

Rights assessment distinguishes citation, bounded quotation, redistribution,
internal use, review use, and public representation. Each permitted use requires
an evidenced basis, jurisdiction, conditions, attribution, duration, and reviewer.

Technical availability is not permission. Unknown rights means Pending Rights,
not unrestricted use. Public citation does not authorize redistribution; internal
review does not authorize public representation.

No copyrighted work, image, table, dataset, or substantial text is duplicated by
the catalog. Where permitted, future independently authored factual summaries
remain traceable to exact Sources without copying protected expression.

Rights changes create a governed Source status/version impact and may block or
withdraw consumer eligibility without altering scientific meaning.
