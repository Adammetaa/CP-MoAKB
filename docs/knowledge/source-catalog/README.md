# Governed Source Catalog

Status: Active

Version: 1.0

## Purpose

The Source Catalog materializes the minimum governed Source layer required to
prepare a future Golden Rice Canonical Knowledge Package. It governs Source
identity, authority, version, rights, coverage, availability, status, retrieval
history, supersession, and traceability only.

A Governed Source is the authoritative representation of one reference without
creating Evidence or Knowledge. It owns no Claim, Concept, Relationship,
Diagnosis, Recommendation, Package membership, or consumer interpretation.

## Authority and Freeze

The existing Source Object, Source Policy, Source Authority Policy, CKP
Architecture, Knowledge Object Model, Knowledge Asset Architecture, KAS, KGS,
Publication Boundary, and Design Freeze remain authoritative and unchanged.

## Implementation Boundary

This family creates no Source Object class, schema, API, registry, parser,
validator, Runtime behavior, scientific extraction, Evidence, Claim, Concept,
Relationship, or production Source record.
