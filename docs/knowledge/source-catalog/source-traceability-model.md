# Source Traceability Model

Status: Active

Version: 1.0

The catalog prepares—but does not implement—the future chain:

> Source -> Evidence -> Claim -> Concept -> Package -> Website

The Source end preserves identity, exact version, publisher, authority scope,
jurisdiction, publication/source dates, retrieval history, custody, integrity,
rights, coverage, status, corrections, retractions, supersession, reviews, and locators.

Future Evidence must reference the exact Source version and locator. Downstream
objects retain their own identities and cannot overwrite Source provenance.
Website citation remains a Representation, not Source ownership.

Missing identity, version, authority, rights, or retrieval provenance blocks any
future use dependent upon it. The catalog creates no Evidence link or scientific Relationship.
