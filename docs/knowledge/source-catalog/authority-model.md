# Source Authority Model

Status: Active

Version: 1.0

Source authority is claim- and scope-specific. The following responsibilities
remain separate:

| Authority | Responsibility |
|---|---|
| Publisher | issues or distributes the reference |
| Scientific Authority | supports scientific subject matter within methods and scope |
| Regulatory Authority | governs legal status in a jurisdiction and effective period |
| Terminology Authority | governs names or terms within a declared system |
| Classification Authority | governs a named classification and version |
| Review Authority | assesses a fixed Source registration or intended use |
| Publication Authority | authorizes a governed representation for an audience |

One organization may hold several roles, but they are recorded independently.
Institutional reputation, official status, or review never establishes universal
truth, local applicability, Evidence sufficiency, or Recommendation authority.
