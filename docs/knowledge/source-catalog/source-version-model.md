# Source Version Model

Status: Active

Version: 1.0

A Governed Source distinguishes stable Source identity, declared edition/version,
publication/release/effective date, retrieval date, retained representation,
checksum where applicable, correction, retraction, replacement, and supersession.

Retrieval date cannot substitute for source or effective date. A newer download
does not prove currency. Changed content or checksum is never silently accepted as
the same version. Dynamic Sources require governed retrieval context and immutable
evidence of the consulted state where rights permit.

Source Version remains separate from Evidence, Knowledge, Package, Review,
Representation, Publication, API, schema, and software versions. This model
defines no identifier or version syntax.
