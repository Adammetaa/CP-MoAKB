# Source Selection Policy

Status: Active

Version: 1.0

Select the smallest Source set sufficient for the declared future Package scope.
Evaluate exact identity/version, authority fit, coverage, jurisdiction, currency,
availability, integrity, rights, reviewability, provenance, and known limitations.

Prefer the responsible official authority for official classifications and
regulatory status; use appropriate scientific authorities for biology and
mechanism. One Source need not—and usually cannot—govern every subject.

Do not select by convenience, reputation alone, search ranking, prior chat,
commercial preference, or desired conclusion. An unavailable source is recorded
as `SOURCE MATERIAL REQUIRED`; Faculty or Owner input without a governed record is
`AUTHORING INPUT PENDING`.

Selection creates no Evidence, Claim, Concept, Relationship, Package membership,
or publication eligibility. Conflicts remain separately traceable for later review.
