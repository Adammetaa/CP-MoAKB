# Fictional Review Examples

Status: Illustrative
Version: 1.0

## Purpose
Explain how the framework is applied without creating real knowledge.
## Scope
The [passing](fictional-passing-review.md) and [blocked](fictional-blocked-review.md) synthetic cases.
## Out of Scope
These examples MUST NOT become candidate data, scientific evidence, advice, or templates for software.
## Authority
The [Knowledge Review Framework](../knowledge-review-framework.md) overrides every illustration here.
## Definitions
**Fictional** means every entity, source, authority, and assertion is invented.
## Required Inputs
No external sources or uploaded documents are used.
## Procedure
Read the candidate, findings, specialist decisions, and final gate in order.
## Decision Rules
Illustrative outcomes MUST NOT establish precedent or acceptance authority.
## Responsibilities
Readers MUST preserve the fictional boundary when citing these examples.
## Failure Modes
Treating an invented statement as agricultural content or recommendation.
## Escalation
Any ambiguity about realism MUST be corrected before publication of documentation.
## Audit Requirements
Examples MUST retain explicit fictional labels and no external citations.
## Examples
The passing case closes its only revision independently.
## Non-examples
Real crops, pests, diseases, chemicals, institutions, or sources MUST NOT appear.
## Change Control
Changes require documentation and fictional-boundary review.
## Future Considerations
Additional examples MAY cover process variants without adding domain knowledge.
