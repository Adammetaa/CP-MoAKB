# Knowledge Editorial Handbook

Status: Active
Version: 1.0

This family translates the [Knowledge Constitution](../constitution/knowledge-constitution.md),
[Knowledge Authoring Standards](../README.md), and
[Knowledge Governance Standards](../governance/README.md) into human editorial
procedures. It is subordinate operational guidance: it creates no authority,
schema, Runtime behavior, accepted terminology, agricultural knowledge, or
publication event.

## Start Here

- [Primary handbook](knowledge-editorial-handbook.md)
- [Workflows](workflows/source-intake-workflow.md): source intake, evidence
  extraction, candidate authoring, terminology, relationships, review, and
  publication readiness
- [Guides](guides/writing-definitions.md): focused authoring decisions
- [Checklists](checklists/author-checklist.md): review instruments
- [Fictional examples](examples/README.md): synthetic demonstrations only

All transitions require an identified human decision. Editorial acceptance MUST
NOT be interpreted as repository publication, a Git tag, a GitHub Release,
package publication, or a knowledge release.
