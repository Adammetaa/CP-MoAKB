# Fictional Editorial Examples

Status: Illustrative
Version: 1.0

These examples are entirely fictional review aids. They contain no real crop,
disease, insect, chemical, authority, source, agricultural claim, diagnosis, or
recommendation. They MUST NOT be treated as candidate data, accepted knowledge,
a template schema, or publication content.

- [Fictional good example](fictional-good-example.md) demonstrates traceability,
  scope, uncertainty, and review separation.
- [Fictional bad example](fictional-bad-example.md) demonstrates prohibited
  editorial shortcuts and includes an annotated correction plan.

The [Knowledge Editorial Handbook](../knowledge-editorial-handbook.md) remains
authoritative over these illustrations.
