# Evidence Reviewer Checklist

Status: Active
Version: 1.0

## Purpose
Verify source fidelity and evidence-to-claim traceability.
## Scope
Identity, locators, context, limitations, conflicts, and rights handling.
## Out of Scope
Evidence review MUST NOT score truth or replace scientific review.
## Authority
Use under the [handbook](../knowledge-editorial-handbook.md), KAS-003, and KAS-004.
## Definitions
**RR** means revision required; **N/A** requires a reason.
## Responsibilities
Evidence Reviewer completes all rows and identifies inaccessible material.
## Procedure
Compare candidate to source; mark one result per row; require corrections for fidelity defects.
## Required Inputs
Source candidate, evidence item, claim links, rights finding, and source access.
## Required Outputs
Checklist, traceability disposition, and revisions.
## Review Points
| Review item | Pass | Fail | N/A | RR | Reviewer notes |
| --- | --- | --- | --- | --- | --- |
| Source identity, version, and locator are verified | [ ] | [ ] | [ ] | [ ] | |
| Paraphrase is faithful and quotation is limited | [ ] | [ ] | [ ] | [ ] | |
| Context, method, population, limitations, date, and jurisdiction remain explicit | [ ] | [ ] | [ ] | [ ] | |
| Support, contradiction, withdrawal, and missing context are preserved | [ ] | [ ] | [ ] | [ ] | |
| Source-to-evidence and evidence-to-claim links are complete | [ ] | [ ] | [ ] | [ ] | |
## Failure Modes
Context stripping, extrapolation, silent harmonization, or inferred access.
## Examples
An unavailable source is marked unavailable and blocks verification.
## Non-examples
A citation without a locator MUST NOT pass.
## Escalation
Meaning questions go to Scientific Review; rights issues to rights review.
## Audit Requirements
Retain comparison findings, source version, decision, and corrections.
## Change Control
Evidence semantics remain governed by KAS-003/004.
## Future Considerations
No machine extraction is authorized; this is not a software form.
