# Terminology Reviewer Checklist

Status: Active
Version: 1.0

## Purpose
Assess multilingual term nominations without conflating labels and identity.
## Scope
Term type, language, context, equivalence, ambiguity, and status.
## Out of Scope
UI text or automatic translation MUST NOT receive terminology authority here.
## Authority
Use under the [handbook](../knowledge-editorial-handbook.md), KAS-005, ADR-006, and ADR-007.
## Definitions
**RR** means revision required; **N/A** requires a reason.
## Responsibilities
Terminology Reviewer declares language competence and completes every row.
## Procedure
Mark one result per row; document sources and explain Fail, N/A, and RR.
## Required Inputs
Candidate identity, term nomination, language, type, context, and evidence.
## Required Outputs
Checklist, term disposition, scope, uncertainty, and revisions.
## Review Points
| Review item | Pass | Fail | N/A | RR | Reviewer notes |
| --- | --- | --- | --- | --- | --- |
| Term is linked to identity but not used as identity | [ ] | [ ] | [ ] | [ ] | |
| Thai, English, scientific, local, and trade statuses are distinct | [ ] | [ ] | [ ] | [ ] | |
| Translation and transliteration are separately evidenced | [ ] | [ ] | [ ] | [ ] | |
| Ambiguous, historical, deprecated, and uncertain terms are explicit | [ ] | [ ] | [ ] | [ ] | |
| UI localization is not presented as accepted terminology | [ ] | [ ] | [ ] | [ ] | |
## Failure Modes
Spelling-based merge, universal local usage, automatic equivalence, or hidden uncertainty.
## Examples
An uncertain Thai term MAY be deferred with context.
## Non-examples
A translated label accepted without review MUST NOT pass.
## Escalation
Scientific names go to Scientific Review; identity disputes to governance.
## Audit Requirements
Retain language competence, evidence, decision, dissent, and term history.
## Change Control
Term status changes require review and preserved history.
## Future Considerations
Vocabulary construction is separately governed; this is not a software form.
