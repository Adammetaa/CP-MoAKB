# Fictional Template Examples

Status: Illustrative
Version: 1.0

## Purpose
Demonstrate human template use without creating real knowledge or candidate data.
## Scope
One [complete](fictional-complete-package.md) and one [incomplete](fictional-incomplete-package.md) fictional package.
## Out of Scope
Examples MUST NOT become schemas, records, sources, authorities, recommendations, or publication content.
## Authority
[Template Governance](../template-governance.md) and all higher authorities override these examples.
## When to Use
Use only for training and review of template completeness.
## Who Completes It
Documentation maintainers preserve the fictional boundary; readers do not submit these as candidates.
## Required Inputs
No external source, uploaded PDF, real agricultural fact, or real regulation is used.
## Template Fields
The examples show human references and statuses, not machine properties or complete domain values.
## Completion Rules
Every identity, source, authority, term, relationship, and assertion MUST remain explicitly invented.
## Prohibited Content
Real crop, disease, insect, chemical, authority, source, regulation, diagnosis, recommendation, or advice.
## Review Requirements
Documentation review MUST confirm fictional status and all governing disclaimers.
## Failure Modes
Realistic names mistaken for facts, copied source text, or example promoted to data.
## Example
The complete package demonstrates process completeness while remaining unaccepted for publication.
## Non-example
A real source filled into the example MUST NOT be committed.
## Audit and Retention
Retain example version, fictional-boundary review, and changes.
## Change Control
Changes require documentation, template-governance, and fictional-content review.
