# Knowledge Population Batch 001

Status: Accepted for internal source-backed representation; not published

Version: 1.0

## Scope

This is the smallest coherent real package extracted from one fixed Department
of Agriculture source. It covers the source's definition of plant disease and
its two source-classified cause categories. It is foundational context for the
Rice Website Disease Detail composition; it does not assert a rice-specific
disease, identify a cause in a field case, or provide management advice.
