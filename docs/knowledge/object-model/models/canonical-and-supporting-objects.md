# Canonical and Supporting Objects

Status: Active

## Purpose

Classify object responsibilities without creating an importance hierarchy.

## Responsibility Groups

- **Scientific meaning carriers:** Concept, Claim, Relationship, Terminology.
- **Evidence and provenance records:** Source, Evidence, Authority.
- **Review and governance records:** Review, Finding, Decision, Unresolved Issue.
- **Lifecycle and publication records:** Lifecycle Event, Publication Record,
  Package Membership.
- **View records:** Representation.

Scientific meaning carriers form or qualify an Asset's semantic nucleus.
Supporting records make that meaning traceable, reviewable, governed, historic,
and faithfully visible. “Supporting” MUST NOT mean optional, secondary in
importance, or lower authority. An Asset MUST remain unaccepted when required
supporting objects are missing, blocked, conflicting, or incompetent.

## Boundaries

No group may inherit another group's authority. Evidence does not create meaning;
review does not rewrite content; lifecycle does not prove correctness;
presentation does not create knowledge. Objects retain independent identity and
audit history even when shown together.

## Future Implementation and Change Control

These groups are conceptual navigation aids, not inheritance, storage, or access
classes. Any change requires object-boundary and authority review.
