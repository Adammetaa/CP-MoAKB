# First Golden Package Plan

Status: Conceptual plan; authoring not started

## Proposed Smallest Set

Prefer one future Insect/Pest subject Package plus exact dependencies: Rice Crop,
relevant Growth Stage or Plant Organ only if evidenced, taxonomic Organism, IRAC
classification/MoA, and the minimum Source/Evidence objects. The candidate subject
is not selected until biology and management Sources are formally materialized.

IRAC is the only currently materialized official source family, but IRAC alone is
not authority for pest identity, biology, crop interaction, Diagnosis, or
Management Recommendation. Therefore Golden authoring is blocked by
`SOURCE MATERIAL REQUIRED`.

## End-to-end Proof

One accepted CKP Version will feed Public Website, SPA Support, Investigation,
Reviewer, and future AI Context Views by exact reference. Each View selects and
summarizes under policy without copying canonical content or changing meaning.

## Acceptance Evidence

The future proof requires exact identities/versions, Source rights and authority,
Claim-Evidence binding, canonical Relationships, composition review, unresolved
issues, dependencies, consumer eligibility, and separate publication authorization.
No Package or real Knowledge is authored in this sprint.
