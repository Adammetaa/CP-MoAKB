# Package Composition Model

Status: Active

Version: 1.0

## Composition

> Knowledge Package -> Package Memberships -> exact Canonical Assets / Objects

Membership may reference Concept, Claim, Terminology, Relationship, Observation
Vocabulary, Source, Evidence, Authority, Unresolved Issue, Review, Decision, and
Lifecycle objects. Each object retains independent identity, version, ownership,
review, and lifecycle.

## Membership Contract

Each membership identifies exact Package and member versions, purpose in scope,
required/optional status, authority, review basis, and limitations. Floating
membership is prohibited. Membership does not copy content, create a Relationship,
promote Evidence, resolve an issue, or transfer publication status.

## Dependencies

A direct dependency is required for Package meaning; an optional dependency adds
governed coverage without changing core scope. Both bind exact versions.
Incompatible or superseded dependencies must be blocked or explicitly governed.
Circular Package dependencies are prohibited.

Disease Packages may reference Crop, Growth Stage, Pathogen, Active Ingredient,
and FRAC Packages rather than copying their contents.
