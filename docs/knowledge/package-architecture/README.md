# Canonical Knowledge Package Architecture

Status: Active

Version: 1.0

## Definition

A Canonical Knowledge Package (CKP) is a governed aggregation and composition
boundary around exact versions of canonical Knowledge Assets and supporting
governance objects. It provides one reusable scientific basis for governed Views
without duplicating the underlying knowledge.

> Sources -> Evidence -> Claims / Concepts / Relationships -> Knowledge Assets
> -> CKP -> governed consumer Views

The CKP is implementation-independent. It is not a production schema, file
format, database record, UI model, Case Record, inference result, or publication.
