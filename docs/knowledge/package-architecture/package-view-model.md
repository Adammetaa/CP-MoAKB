# Package View Model

Status: Active

Version: 1.0

> Canonical Package -> Governed View Composition -> Public Website View / SPA
> Support View / Investigation View / Reviewer View / AI Context View

A View may select, order, label, summarize within policy, and suppress restricted
content for a declared purpose. It preserves Package/member identities, exact
versions, provenance, citations, authority, Review State, publication status,
rights, unresolved issues, and limitations.

No View owns underlying knowledge, invents Relationships, resolves uncertainty,
or changes canonical scientific meaning. View omission does not mean scientific
absence. Representation Version remains separate from Package Version.
