# Active Ingredient Package Profile

Conceptual coverage may reference canonical chemical/biological identity,
accepted names, regulatory records, formulation Concepts, target Relationships,
Mode of Action, IRAC/FRAC/HRAC classifications, resistance Relationships, label
Claims, crop registration, application limitations, jurisdiction, effective
dates, cancellation/expiry, Evidence, and authority.

Registration does not equal Recommendation. Historic registration MUST NOT be
presented as current registration, and membership never implies product preference.
