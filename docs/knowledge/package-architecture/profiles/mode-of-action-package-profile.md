# Mode of Action Package Profile

Conceptual coverage may reference MoA identity, classification system, governing
authority, group, target site/process, mechanism, affected physiological system,
applicable Active Ingredients, resistance-mechanism references, cross-resistance,
rotation/mixture governance, classification version, Evidence, and limitations.

IRAC, FRAC, and HRAC remain separate authority systems. MoA does not equal
Treatment Recommendation, Product Recommendation, or resistance Decision.
