# Package Publication Model

Status: Active

Version: 1.0

Package acceptance, publication readiness, publication authorization, repository
presence, Git tag, release, Website visibility, and package-index publication are
separate states and decisions.

Publication binds an exact Package Version, exact eligible members and
dependencies, audience, representation, rights, authority, and audit record. It
does not publish restricted members by implication or change scientific meaning.

Withdrawal, correction, deprecation, and supersession preserve history and direct
consumers to approved replacements where applicable. This sprint creates no
publication candidate or authorization; repository status remains `not_published`.
