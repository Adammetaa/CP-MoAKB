# Package Identity and Versioning

Status: Active

Version: 1.0

Package identity remains stable and separate from all member identities,
representations, labels, URLs, and paths. Package Version identifies one exact
composition and dependency set.

A new Package Version is required for member addition/removal, exact member
version update, Relationship-set change, dependency change, consumer eligibility
change, composition-affecting review change, rights change, or publication
readiness change. Editorial changes with no meaning or composition effect follow
governed correction rules.

Package Version, Knowledge Version, Publication Version, Representation Version,
Review Version, and Authority Version remain independent. This architecture
defines no numeric syntax. Supersession preserves the prior version and audit trail.
