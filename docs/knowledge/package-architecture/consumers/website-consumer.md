# Website Consumer Contract

The Website is a Representation layer. It may present eligible Overview,
Identity, Biology, Observation, Mechanism, Evidence, Related Knowledge,
Management-category, Mode-of-Action, Resistance, Source, and Limitation Views.

It MUST preserve citations and review/publication state and suppress confidential
content. It MUST NOT own or duplicate Package knowledge, invent Relationships, or
convert Management knowledge into Recommendation.
