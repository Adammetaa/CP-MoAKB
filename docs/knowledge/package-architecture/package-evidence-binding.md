# Package Evidence Binding

Status: Active

Version: 1.0

## Required Chain

> Package -> Member Asset -> Claim -> Evidence -> Source -> Authority

Every public or scientific statement must resolve toward exact governed Evidence
and Source provenance. A CKP never hides provenance or turns coverage summaries
into Evidence.

Evidence roles include supporting, contradicting, limiting, unavailable, outdated,
superseded, and jurisdiction-limited Evidence. Roles remain claim- and scope-bound;
no numerical truth or confidence score is defined.

Missing or conflicting Evidence remains an Unresolved Issue or blocker. Package
acceptance cannot silently convert it into support. One Source may support Evidence
in many Packages, and one Package may reference many Sources through exact objects.
