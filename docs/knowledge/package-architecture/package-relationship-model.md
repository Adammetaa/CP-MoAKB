# Package Relationship Model

Status: Active

Version: 1.0

CKPs compose canonical Relationship Objects across Crop, Growth Stage, Plant
Organ, Observation, Disease, Pathogen, Pest, Weed, Mechanism, Environment,
Management Option, Active Ingredient, Mode of Action, Resistance, and Regulatory
Status. Each Relationship retains exact source/target versions, type, direction,
basis, Evidence, authority, review, lifecycle, and limitations.

Package membership, adjacency, shared terminology, dependency, consumer
navigation, or co-occurrence MUST NOT create a Relationship automatically.
Observed Association does not equal Biological Cause. Evidence Support does not
equal Confirmed Diagnosis. Inferred or computed links require separate governed
authoring and review before becoming canonical.
