# Package Source Intake Model

Status: Active

Version: 1.0

> Source -> Source Identity -> Rights Review -> Authority Scope -> Evidence
> Extraction -> Claim Candidate -> Scientific Review -> Canonical Object ->
> Package Membership

Intake records exact edition/version, locator, retrieval/custody, authorship,
publisher, jurisdiction, dates, rights, authority scope, transformations, and
limitations. Evidence extraction preserves exact provenance and never treats
Source reputation as universal truth.

Chat history is not a scientific Source or canonical Evidence. Faculty-derived
input requires a materialized governed Source or explicit Owner-authored
Source/Evidence record. Otherwise record `SOURCE MATERIAL REQUIRED` or
`AUTHORING INPUT PENDING`.

One document may contribute Evidence to many Packages; one Package may rely on
many Sources. One document does not equal one Package.
