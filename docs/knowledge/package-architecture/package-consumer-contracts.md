# Package Consumer Contracts

Status: Active

Version: 1.0

All consumers share the same exact CKP basis through purpose-specific governed
Views. Consumers may select, order, label, summarize within policy, and suppress
restricted content; they cannot change canonical scientific meaning.

| Consumer | Governed purpose | Permanent prohibition |
|---|---|---|
| Website / Knowledge Explorer | public eligible explanation and navigation | canonical ownership, duplication, inference, recommendation |
| SPA Assistant | explain facts, mechanisms, Evidence, gaps, categories, and limits | confirm Diagnosis, select pesticide, rank product, bypass Human Review |
| Investigation Engine | expose relationships for questions, Evidence needs, hypotheses, differentials | direct Observation-to-Diagnosis or Observation-to-Pesticide path |
| Human Review | inspect full authorized composition, conflict, rights, decisions, and history | create truth by UI state or silently re-author Claims |
| Future AI | consume approved, provenance-aware, versioned context | treat chat, Candidate, UI copy, confidence, or generated output as Knowledge |

Detailed contracts are indexed in [Consumers](consumers/README.md).
