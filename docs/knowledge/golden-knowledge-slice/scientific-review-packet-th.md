# ชุดเอกสารทบทวนทางวิทยาศาสตร์: Golden Knowledge Slice

สถานะ: รอการทบทวนโดยผู้เชี่ยวชาญที่เป็นมนุษย์

เวอร์ชันของข้อกล่าวอ้างที่ทบทวน: `CL-GOLDEN-001/v1`, `CL-GOLDEN-002/v1`

## 1. วัตถุประสงค์และขอบเขต

เอกสารนี้ช่วยให้นักปฐพีวิทยาหรือผู้เชี่ยวชาญโรคข้าวเปรียบเทียบข้อความจาก
แหล่งข้อมูล หลักฐานที่คัดมาแบบจำกัดขอบเขต และข้อกล่าวอ้างฉบับคงที่
เพื่อประเมินว่า **ข้อกล่าวอ้างทั้งสองยอมรับได้ทางวิทยาศาสตร์หรือไม่**

การทบทวนนี้ไม่ใช่การวินิจฉัย ไม่ใช่คำแนะนำ ไม่ใช่การเลือกสารกำจัดศัตรูพืช
ไม่ใช่การยอมรับ Package และไม่ใช่การอนุญาตให้เผยแพร่ การอนุมัติในการทบทวนนี้
ไม่เท่ากับการเผยแพร่หรือการยืนยันว่าเป็นความจริงสากล

## 8. ผลต่อ `UI-GOLDEN-001` (ห้ามปิดอัตโนมัติ)

ปัจจุบัน issue นี้บล็อกการยอมรับ Claim และการเขียนวัตถุขั้นถัดไป เพราะยังไม่มี
การมอบหมายผู้ทบทวนที่เป็นมนุษย์ หลักฐานความสามารถที่ตรงขอบเขต
คำประกาศผลประโยชน์ทับซ้อน และผลทบทวนทางวิทยาศาสตร์ของ Claim ฉบับคงที่

ผู้ทบทวน/ผู้มีอำนาจเลือกหนึ่งข้อ:

- ☐ `resolves` — เอกสารความสามารถ ความเป็นอิสระ คำประกาศ ผลการทบทวน
  เหตุผล และการยืนยันความครบถ้วนมีครบสำหรับ Claim ทั้งสอง
- ☐ `partially resolves` — ระบุส่วนที่ครบและส่วนที่ยังขาด: __________
- ☐ `does not resolve` — ระบุเหตุผล: _____________________________

การเลือกข้างต้นเป็นข้อมูลประกอบการพิจารณา issue เท่านั้น ผู้ทบทวนไม่มีอำนาจ
ปิด `UI-GOLDEN-001` โดยอัตโนมัติ ผู้มีอำนาจตาม governance ต้องตรวจสอบ
completion evidence และบันทึกการตัดสินใจแยกต่างหาก

## ขั้นตอนสั้นสำหรับผู้ทบทวน

1. กรอกข้อมูลผู้ทบทวนและคำประกาศผลประโยชน์ทับซ้อนก่อนอ่านเนื้อหา
2. เปรียบเทียบ Source context → Evidence → Claim ทีละรายการ
3. กรอกผลประเมิน Finding สิ่งที่ต้องแก้ และ Evidence ที่ต้องเพิ่ม
4. เลือก disposition ที่อนุญาตหนึ่งรายการต่อ Claim พร้อมเหตุผลและลงวันที่
5. ประเมินผลต่อ `UI-GOLDEN-001` โดยไม่ปิด issue เอง แล้วส่งคืนผู้ประสานงาน

Concept, Terminology, Relationship, CKP, Package acceptance และ publication
อยู่นอกขอบเขตของเอกสารนี้และห้ามสร้างจากการกรอกแบบทบทวนนี้โดยอัตโนมัติ
