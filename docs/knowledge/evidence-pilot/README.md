# Golden Source to Evidence Pilot

Status: Evidence candidates reviewed

Version: 1.0

## Purpose

This pilot applies the existing KES pipeline to one Project Owner-approved real
rice-subject Source and stops at reviewed Evidence Candidates:

> Governed Source -> Relevant Section -> Relevant Passage -> Citation ->
> Evidence Candidate -> Evidence Review -> STOP

## Boundary

These candidates preserve bounded Source wording and context. They are not
Claims, Concepts, Terminology, Relationships, accepted Knowledge, Knowledge
Objects, Package membership, Diagnosis, Recommendation, or Website content.

The source artifact remains outside the repository. This family does not copy the
document, summarize it, infer biology, merge passages, or authorize publication.
