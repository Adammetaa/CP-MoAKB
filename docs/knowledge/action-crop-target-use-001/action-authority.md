## Accepted Thai operational evidence

`AE-076-BPH-001/v1` binds `CL-076-BPH-ET-001/v1` to
`EV-076-BPH-ET-001/v1` and the Rice Department locator above.

| Field | Governed value |
| --- | --- |
| Subject | brown planthopper, *Nilaparvata lugens* |
| Threshold type | Economic Threshold |
| Crop | rice |
| Measurement unit | insects per plant |
| Trigger | 10 or more insects per plant |
| Measurement method | field average count; exact sampling protocol remains incomplete |
| Geography | Phan District, Chiang Rai, Thailand |
| Production context | 2023 wet-season farmer-field efficacy activity |
| Management implication | Management Review may open; pesticide use does not follow automatically |
| Thai applicability | `THAI_OPERATIONAL_EVIDENCE_WITH_LIMITATION` |

Limitations are material. The report describes the observed average using
`per point`, while stating the Economic Threshold using `per plant`. It is a
single field activity and does not independently establish current registration,
comparative efficacy, product selection, or dose. Human review remains available.

## Reference evidence

- `AE-076-LF-REF-001/v1`: IRRI describes damage importance when more than half
  of the flag leaf and the next two youngest leaves per tiller are affected. This
  is `REFERENCE_EVIDENCE_ONLY`; Thai operational applicability is unresolved.
- `AE-076-BPH-REF-001/v1`: IRRI supplies a monitoring number and a seedbed-only
  multi-condition action rule involving planthoppers per stem, natural enemies,
  and flooding feasibility. It is not converted into the Thai rule above.

Economic Threshold, monitoring number, damage-importance criterion, and field
burden remain distinct concepts.
