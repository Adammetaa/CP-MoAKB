## Operational authority matrix

| Authority | Can establish | Cannot establish alone |
| --- | --- | --- |
| Rice Department / academic biological Source | identity, biology, symptoms/damage, field context, directly stated management | current registration, current MoA classification, current resistance status |
| IRAC v11.5 | insecticide MoA classification | insect efficacy, Thai registration, Recommendation |
| FRAC 2026 | fungicide MoA classification | disease efficacy, Thai registration, Recommendation |
| HRAC 2026 | herbicide MoA classification | weed efficacy, Thai registration, Recommendation |
| Thai DOA registry snapshot | exact administrative record fields that can be bound to a record | efficacy, suitability, best treatment or Recommendation |

None alone establishes case-specific Recommendation, best treatment, guaranteed
control or resistance. `CONTROL FAILURE != RESISTANCE` remains mandatory.
