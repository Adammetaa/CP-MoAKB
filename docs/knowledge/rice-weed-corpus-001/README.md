Status: Accepted for bounded internal composition; not published

This corpus reuses the governed Department of Agriculture training-manual Source
and materializes eight rice-field weed subjects explicitly named in Chapter 3.
The Source supports Thai common-name identity, rice-field occurrence, and group
membership. It does not support scientific names or species-level morphology;
those fields remain unresolved rather than inferred.
