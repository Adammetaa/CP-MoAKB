# Packages, Website Views, and Traceability

`CKP-RWC-001/v1` through `CKP-RWC-008/v1` package the eight Concepts in inventory
order. `WV-RWC-001/v1` through `WV-RWC-008/v1` are their Thai-first Website Views.
Each package contains identity, bounded group/context Claims, Evidence references,
Source/version, exact locators, rights, review state, limitations and unresolved
issues. Unsupported sections are omitted.

| CKP / View range | Visible coverage |
| --- | --- |
| `CKP-RWC-001/v1` / `WV-RWC-001/v1` to `CKP-RWC-003/v1` / `WV-RWC-003/v1` | three narrow-leaved/grass candidates |
| `CKP-RWC-004/v1` / `WV-RWC-004/v1` to `CKP-RWC-005/v1` / `WV-RWC-005/v1` | two broadleaf candidates |
| `CKP-RWC-006/v1` / `WV-RWC-006/v1` to `CKP-RWC-008/v1` / `WV-RWC-008/v1` | three sedge candidates |

Bidirectional traceability is:

`Website View -> CKP -> Claim -> Evidence -> GS-DOA-HAZARDOUS-SALES-2019-001/v1 -> printed/PDF page + numbered section`.

The Explorer projection carries rights-safe summaries, not a parallel Source or
Knowledge database. The SP Assistant links to the same Views and asks for missing
observations before surfacing management context.
