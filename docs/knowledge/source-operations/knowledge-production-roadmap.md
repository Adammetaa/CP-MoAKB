# Immediate Knowledge Production Roadmap

Status: Governed sequence

Version: 1.0

> Governed Source -> Knowledge Extraction -> Evidence -> Claim -> Knowledge
> Objects -> Canonical Knowledge Package -> Review -> Publication Authorization
> -> Knowledge Explorer -> SPA Assistant -> Investigation Engine

The roadmap is sequential responsibility, not automated data flow. Each arrow
requires the existing explicit review, identity/version, authority, rights,
traceability, lifecycle and decision gates. A stage may return, reject, defer or
produce no downstream object.

Knowledge Explorer, SPA Assistant and Investigation Engine consume governed
representations of the same canonical basis and never become sources of truth.
Publication Authorization is separate from Knowledge or Package acceptance.

The immediate production work is: acquire one approved rice-subject Source,
complete Source operations, apply KES, review the minimum Golden object network,
compose the exact-version CKP, complete Package Review and obtain separate
Publication Authorization. No additional architecture or Runtime sprint is
required; actual source acquisition and scientific authoring remain governed work.
