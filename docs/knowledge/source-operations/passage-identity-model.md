# Passage Identity Model

Status: Active

Version: 1.0

A Passage is an immutable governed reference to a bounded location within one
exact Source version. Passage is not Evidence, Claim, Concept, Terminology,
Relationship, or Knowledge.

Passage identity is independently reviewable and binds the exact Source identity
and version, document-version citation, page/section/paragraph or other stable
locator method, passage extent, language/translation context where applicable,
rights constraints, creation/review role, review status, and traceability history.

Changing the Source version, locator, extent, or cited content requires a new or
superseding Passage identity; it is never silently retargeted. Section membership
provides location context and does not create scientific meaning.

Passage review confirms deterministic re-location and fidelity only. Evidence
arises later through KES interpretation and separate Evidence Review. This model
defines no identifier syntax, anchoring algorithm, OCR, text extraction, database,
schema, or API.
