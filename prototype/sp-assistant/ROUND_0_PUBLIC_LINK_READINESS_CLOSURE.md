# Round-0 UX and Public-Link Readiness Closure

M0A.1 closes the bounded usability findings observed during Round 0. It does not deploy a public link and does not change scientific, management, regulatory, or Human Decision authority.

## Conversation presentation boundary

CP-MoAKB continues to decide what evidence is needed, why it matters, whether evidence is sufficient, and when questioning stops. The presentation layer only expresses that governed request as one natural Thai question. Internal evidence concepts remain stored and auditable but are excluded from normal field Chat. Unknown concepts fail to a generic affected-versus-normal comparison instead of displaying an internal code.

The response pattern is acknowledge → briefly reflect what was understood → ask one useful question. Cannot-answer turns remain unanswered and stop the immediate loop. Corrections append immutable lineage and supersede prior structured facts without rewriting raw history. A failed-control report remains a review signal only and cannot establish resistance, efficacy failure, a dose change, repeat application, or Mode-of-Action switch.

## Runtime recovery

Common scoped URL construction omits null and undefined values. Server endpoints still enforce every mandatory Field, Season, and Case identifier. The Chat submission state is released in a `finally` path after network, provider, authentication, authorization, server, or malformed-response failures. The user's local message remains visible and retryable.

Google Satellite remains the preferred provider. Missing configuration, script failure, `gm_authFailure` (including referer authorization failure), initialization exceptions, runtime failure, and a bounded readiness timeout switch the same surface to the attributed OpenStreetMap adapter. Preview mode renders a fitted polygon without numbered vertices or edit handles; draw mode retains numbered vertices and editing controls.

## Preserved safety boundaries

- The `FIELD_CAPTURE_ALPHA` navigation remains แปลง / แชท / โปรไฟล์ and keeps F1, F2, Step H, and Step I capabilities disabled.
- Image capture remains primary, while automated perception is optional. Unavailable perception preserves the image for manual review and creates no diagnosis, absence finding, or management recommendation.
- Learning Signals remain operational review inputs. They are not Evidence, scientific truth, Learning Candidates, Canonical Knowledge, or automatic promotion.
- Step C remains the management-sufficiency authority. Conversation presentation creates no scientific authority.
- Cross-device reconstruction uses server conversation state, and ownership checks continue to isolate Fields, Cases, messages, images, and Learning Signals.

## Validation status language

Automated mobile-width checks cover 360, 390, 400, 412, and 430 px contracts. Real-device keyboard, camera, Google credential, cross-device, and public HTTPS checks still require the controlled Round-0 walkthrough. `REAL_FIELD_VALIDATION` remains `NOT_RUN`. This closure is not production readiness, scientific validation, diagnostic-accuracy validation, deployment authorization, or publication approval.
