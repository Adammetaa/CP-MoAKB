# SP Assistant — Local Internal Pilot Review

สถานะ: ใช้งานรีวิวทีมบน Local network ได้แล้ว

URL: `http://10.67.183.89:4173/`

รหัสต้นแบบ: `1234`

## ก่อนเริ่ม

- เปิดคอมเครื่องที่รัน Pilot และอย่าปิดหน้าต่าง Server
- ให้มือถือ/คอมของผู้รีวิวอยู่ Wi‑Fi เดียวกัน
- ตรวจว่าหน้า `/health` แสดง `storage_ready: true` และ `ai_configured: true`
- สร้าง Backup และ Export ก่อนเริ่มรอบรีวิว

## เส้นทางทดสอบหลัก

1. Login ด้วย `1234`
2. อนุญาตหรือข้าม GPS ตามสถานการณ์
3. เปิดแปลงเดิม ตรวจภาพดาวเทียม Weather และข้อมูลระยะข้าว
4. เข้า Field Chat ส่งข้อความหนึ่งครั้ง
5. ตรวจว่ามี “กำลังประมวลผล…” และได้รับคำตอบ
6. Refresh แล้วตรวจว่าบทสนทนายังอยู่
7. เข้า “เรียนรู้” ทดลองค้นข้อมูลอย่างน้อย 2 หมวด
8. เปิดที่มาและข้อจำกัดของผลค้นหา
9. กด Team Review: ใช้ได้ / ข้อมูลไม่ตรง / ต้องเพิ่มข้อมูล
10. เข้า Profile ตรวจ Export และ Backup
11. แนบ JPG/PNG/WebP ไม่เกิน 6 MB และตรวจว่าแสดง “ยังไม่ได้วิเคราะห์”

## สิ่งที่ควรรีวิว

- ใช้มือเดียวบนมือถือได้หรือไม่
- ชื่อปุ่มและข้อความเข้าใจได้หรือไม่
- ภาพแปลงช่วยให้ระบุพื้นที่จริงได้หรือไม่
- ข้อมูลพันธุ์ข้าว วันที่ปลูก ระยะข้าว และ CMP ตรงกับความเข้าใจของทีมไหม
- คำตอบ Field Chat อยู่ในขอบเขตช่วยสังเกตหรืออ้างเกินหลักฐานหรือไม่
- ข้อมูลจากศูนย์เรียนรู้มีที่มาและข้อจำกัดเพียงพอหรือไม่
- จุดใดกดแล้วไม่ทำงาน โหลดช้า หรือทำให้ผู้ใช้สับสน

## วิธีเก็บผลรีวิว

- กด Team Review ในหน้าเรียนรู้ทุกครั้งที่พบปัญหา
- ใช้ Export JSON/CSV หลังจบรอบ
- คัดลอกไฟล์จาก `data/exports/` ไป Google Drive หลังสร้างเสร็จแล้ว
- ห้าม sync `pilot.sqlite` สดผ่าน Google Drive ระหว่างมีผู้ใช้งาน

## ขอบเขตที่ยังไม่ใช่ Production

- รหัสร่วม `1234` ใช้สำหรับ Pilot เท่านั้น
- ข้อมูลยังอยู่บนเครื่อง Local ไม่ใช่ Cloud
- ภาพที่แนบถูกเก็บเป็นหลักฐาน `NOT_ANALYZED`
- ความรู้ช่วยจัดสิ่งที่ควรสังเกต ไม่ใช่การวินิจฉัยหรือคำแนะนำสารเคมี
- การ Backup บน Google Drive เป็นการสำรอง ไม่ใช่ฐานข้อมูลออนไลน์ร่วมกัน
